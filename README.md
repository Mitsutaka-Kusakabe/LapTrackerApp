# 🏃 LapTracker - 陸上中長距離向けストップウォッチ Androidアプリ (v0.9.0)

[![Version](https://img.shields.io/badge/version-0.9.0-blue.svg)](https://github.com/Mitsutaka-Kusakabe/LapTrackerApp)

陸上競技（800m〜5000m、3000mSC、10000m等）のマネージャー・コーチ・選手本人が、**ラップタイム計測・高度な比較分析・1画面でのSNS共有** をスムーズに行うために開発された特化型 Android アプリです。

標準ストップウォッチアプリの「横テーブル表示のため1画面スクリーンショットで全ラップを共有しにくい」という悩みを解消し、現場でのハンズフリー音声計測や充実したデータ比較機能を提供します。

---

## 🌟 主な特徴・機能概略

1. **⏱️ 1/1000秒（ミリ秒）超高精度タイマー**
   - 毎フレーム描画（`awaitFrame`）と `System.currentTimeMillis()` による完全ミリ秒精度（`03:58.402` 表示）。

2. **📍 通過地点プリセット ＆ 任意カスタムラップセット作成**
   - **標準プリセット**:
     - **800m**: 400m, 800m
     - **1500m**: 400m, 800m, 1000m, 1200m, 1500m
     - **3000m**: 400m, 800m, 1000m, 1200m, 1600m, 2000m, 2400m, 2800m, 3000m
     - **5000m**: 400m刻み ＋ 1000m刻みポイント
   - **カスタム作成**: 任意の種目名（例: `2000mSC`, `4x400m`, `400m×5本`）と通過地点メートルを自由に追加・保存・切替可能。

3. **🗣️ 選べる2つのハンズフリー自動ラップトリガー**
   - **単語音声認識モード**: 「400」「800」「1000」「はい」「ラップ」などの掛け声や全距離数値を検知し、部分認識（`onPartialResults`）で即座にラップ記録。
   - **超高速音量ピーク検知モード (0msラグ)**: マイクに入る大きな声・ホイッスル・掛け声の音量エネルギー（`AudioRecord`）に **0ms（遅延なし）** で即座に反応。

4. **📲 1画面スクショ最適化 ＆ LINE/SNS直接共有**
   - **選手名・大会名・日付・種目・トータルタイム・全ラップ縦リスト** が1画面内に整然と収まるカードレイアウト。
   - ワンタップで高画質PNG画像を自動生成し、LINEやSNSへ直接シェア可能。

5. **📊 3つの高度な比較分析モード**
   - **① 差分表示**: 比較対象レースとのラップタイム差分（`+1.230s` / `-0.850s`）を青/赤で視覚化。
   - **② 重ね合わせ折れ線グラフ**: 2つのレースのラップ推移をCompose Canvasで2本の線としてグラフ化。
   - **③ ２画面並列表示 (Split View)**: 2つのレースのラップ一覧を左右カラムでダイレクト比較。

6. **📜 履歴管理・検索・任意2件直接比較・削除**
   - 選手名・大会名・種目でのリアルタイム検索。
   - 履歴一覧から任意の2件にチェックを入れて直接比較画面へジャンプ可能。

7. **✏️ 現場の誤操作防止 ＆ ラップ編集・差分自動再計算 (v0.9.0)**
   - **二重計上防止ガード**: 全チェックポイント通過後の自動フィニッシュ昇格 ＆ 連打チャタリング防止。
   - **ラップ修正ダイアログ**: 不要な誤タップをワンタップで削除（前後の区間ラップタイムを自動再計算）したり、通過距離（メートル）の手動修正が可能。

8. **💾 端末ストレージへの自動永続化 (v0.9.0)**
   - 記録・編集された全レースデータは端末内部ストレージ（JSON形式）に自動保存され、アプリ再起動後も安全に維持。

## 🛠️ 機能詳細

### 1. レース設定画面 (Setup Screen)
- **入力項目**: 選手名（人）、大会名・競技会名、計測日時（デフォルト：現在時刻、編集可能）。
- **ラップセット選択**: プリセット（800m〜5000m）または「＋ カスタム作成」から自由選択。
- **トリガー設定**: タップ操作 ＋ 音声認識（単語認識 / 0ms音量ピーク）のON/OFF切り替え。

### 2. 計測画面 (Timer Screen)
- **屋外視認性重視のデカ文字デザイン**: 黒背景 × ネオンイエロー/シアンの高コントラストカラー。
- **動的進捗インジケータ**: タップ/音声トリガーごとに「次通過地点（例: 400m ➔ 800m ➔ 1000m）」が自動で繰り上がり。
- **デュアル操作**: 画面のどこをタップしてもラップ記録可能。

### 3. 結果・共有画面 (Result & Share Screen)
- **スクショ共有専用カード**: スクロール不要で全情報が1枚に収まる縦型デザイン。
- **LINE / SNS共有インテント**: 一発でAndroidの共有シートが起動し画像送信。

### 4. 比較分析画面 (Compare Screen)
- 履歴の中の「任意のレース1 🟡」と「任意のレース2 🔵」を選択し、3通りの視点（差分・グラフ・並列）で分析。

## 🚀 利用方法

1. **レースの準備・スタート**
   - アプリ起動後、選手名・大会名を入力し、種目（例: 1500m）を選択します。
   - 「⏱️ 計測スタート」を押すと計測画面へ遷移します。
   - 「▶ タップして開始」でタイマーが起動します。

2. **ラップタイムの記録**
   - 選手がチェックポイントを通過するごとに、画面をタップするか、掛け声（「400！」「800！」「はい！」など）を発声します。
   - 自動的に次の通過地点へインジケータが進みます。

3. **計測完了と結果共有**
   - フィニッシュ後、「🏁 フィニッシュ・保存」を押すと結果画面へ遷移します。
   - 「📲 LINE / SNSに1画面共有」を押すと共有画像が作成され、LINE等のアプリへ送信できます。

4. **過去の記録と比較する**
   - 履歴一覧画面を開き、比較したい2つのレースのチェックボックスをオンにして「📊 選択した2件を比較分析する」をタップします。

## 🏗️ ビルド・動作環境

### 動作推奨環境
- **対応OS**: Android 8.0 (API レベル 26) 以上
- **推奨端末**: マイク搭載 Android スマホ実機

### 技術スタック
- **開発言語**: Kotlin 2.x
- **UI フレームワーク**: Jetpack Compose (Material 3)
- **アーキテクチャ**: Repository Pattern & StateFlow
- **音声処理**: Android SpeechRecognizer & AudioRecord (Native Mic Thread)
- **ビルドツール**: Gradle 9.x / Android SDK 36 (Java 17)

### コンパイル・ビルド手順

```powershell
# リポジトリのクローン
git clone https://github.com/Mitsutaka-Kusakabe/LapTrackerApp.git
cd LapTrackerApp

# デバッグAPKのビルド
./gradlew assembleDebug

# 接続されたAndroid実機へのインストール・起動
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r app/build/outputs/apk/debug/app-debug.apk
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" shell am start -n jp.co.mojaxmoja.laptracker/.MainActivity
```
